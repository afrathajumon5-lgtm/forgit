
# 📚 Study Tracker

A simple and user-friendly Study Tracker web application that helps students organize their subjects, manage study tasks, and track their study progress.

## ✨ Features

- Add, edit, and delete subjects
- Add, edit, and delete study tasks
- Mark subjects and tasks as completed
- Set due dates for tasks
- View task status (Completed, Overdue, Due Today, Upcoming)
- Filter tasks by All, Pending, and Completed
- Search subjects
- Dashboard to track total, completed, and pending subjects
- Progress bar to monitor study progress
- Save data using Local Storage
- Responsive design for different screen sizes

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Browser Local Storage

## 🚀 How to Run

1. Clone or download this repository.
2. Open the `study-tracker` folder.
3. Open `index.html` in your web browser.
4. Start managing your study subjects and tasks!
